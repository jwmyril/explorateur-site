API piblik Eksploratè Ayiti a

Tout done Eksploratè a, nan fichye JSON sit la bay dirèkteman : gratis, san kle, san w pa bezwen enskri. Chak valè gen sous li, ane li ak estati li.

Sa v1 an garanti

  • Yon adrès nan /api/v1/ pa chanje fòm : nou ka ajoute yon chan, men okenn chan p ap disparèt ni chanje non.
  • Sa ki ta kase yon pwogram ki deja la ap ale nan /api/v2/, e v1 an ap rete disponib.
  • Valè yo se menm valè ki nan fichye nou pibliye yo ; yon valè ki manke se null, li pa janm zewo.

# Python
import json, urllib.request
req = urllib.request.Request("https://explorateur.atmart.ltd/api/v1/indicateurs/IND-POP-002.json",
                             headers={"User-Agent": "mon-projet/1.0"})
v = json.load(urllib.request.urlopen(req, timeout=30))
print(v["valeurs"][0])

// JavaScript

Si w itilize l anpil

Bay pwogram ou a yon non nan antèt User-Agent la (pa egzanp « mon-projet/1.0 ») : pa-dife sit la refize (erè 403) demann ki pote non otomatik kèk bibliyotèk, tankou urllib Python. requests, R, curl ak navigatè yo pase san w pa bezwen regle anyen.

Fichye yo pa gen limit. Si w bezwen rele yo trè souvan oswa mete yo nan yon pwodwi, ekri sales@atmart.ltd : kle ak limit pou sa ap vini sou yon sèvis apa, san nou pa retire anyen nan API gratis sa a.
