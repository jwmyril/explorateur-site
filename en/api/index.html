Haiti Explorer public API

All the Explorer data, as JSON files served like the site: free, with no key and no sign-up. Every value carries its source, year and status.

What v1 guarantees

  • An address under /api/v1/ keeps its shape: a field may be added, none is removed or renamed.
  • Anything that would break an existing program goes to /api/v2/, and v1 stays served.
  • Values are those of the published files, unchanged; a missing value is null, never zero.

Endpoints

AddressContent
/api/v1/index.jsonVersion, update date and list of endpoints
/api/v1/territoires.jsonThe 192 territories: country, departments, arrondissements, communes
/api/v1/indicateurs.jsonThe 114 indicators: names, units, definitions and limits in 4 languages
/api/v1/indicateurs/IND-POP-001.jsonThe values of one indicator, commune by commune
/api/v1/communes/HT0111.jsonAll values of one commune (by code, e.g. HT0111)

Examples

curl -s https://explorateur.atmart.ltd/api/v1/communes/HT0111.json

# Python
import json, urllib.request
req = urllib.request.Request("https://explorateur.atmart.ltd/api/v1/indicateurs/IND-POP-002.json",
                             headers={"User-Agent": "mon-projet/1.0"})
v = json.load(urllib.request.urlopen(req, timeout=30))
print(v["valeurs"][0])

// JavaScript
fetch("https://explorateur.atmart.ltd/api/v1/territoires.json").then(r => r.json()).then(console.log);

Heavy use

Identify your program with a User-Agent header (for example “my-project/1.0”): the site's firewall refuses (error 403) requests carrying the default identifier of some libraries, including Python's urllib. requests, R, curl and browsers work without any setting.

The files are served without quotas. For very frequent calls or product integration, write to sales@atmart.ltd: dedicated keys and quotas will come on a separate service, without removing anything from this free API.
