API publique de l'Explorateur Haïti

Toutes les données de l'Explorateur, en fichiers JSON servis comme le site : gratuites, sans clé et sans inscription. Chaque valeur porte sa source, son année et son statut.

Ce que la v1 garantit

  • Une adresse de /api/v1/ ne change pas de forme : un champ peut s'ajouter, aucun ne disparaît ni ne change de nom.
  • Ce qui casserait un programme existant ira en /api/v2/, et la v1 restera servie.
  • Les valeurs sont celles des fichiers publiés, à l'identique ; une valeur absente vaut null, jamais zéro.

Adresses

AdresseContenu
/api/v1/index.jsonVersion, date de mise à jour et liste des adresses
/api/v1/territoires.jsonLes 192 territoires : pays, départements, arrondissements, communes
/api/v1/indicateurs.jsonLes 112 indicateurs : noms, unités, définitions et limites en 4 langues
/api/v1/indicateurs/IND-POP-001.jsonLes valeurs d'un indicateur, commune par commune
/api/v1/communes/HT0111.jsonToutes les valeurs d'une commune (par code, ex. HT0111)

Exemples

curl -s https://explorateur.atmart.ltd/api/v1/communes/HT0111.json

# Python
import json, urllib.request
req = urllib.request.Request("https://explorateur.atmart.ltd/api/v1/indicateurs/IND-POP-002.json",
                             headers={"User-Agent": "mon-projet/1.0"})
v = json.load(urllib.request.urlopen(req, timeout=30))
print(v["valeurs"][0])

// JavaScript
fetch("https://explorateur.atmart.ltd/api/v1/territoires.json").then(r => r.json()).then(console.log);

Usage intensif

Identifiez votre programme par un en-tête User-Agent (par exemple « mon-projet/1.0 ») : le pare-feu du site refuse (erreur 403) les requêtes qui portent l'identifiant par défaut de certaines bibliothèques, dont urllib de Python. requests, R, curl et les navigateurs passent sans réglage.

Les fichiers sont servis sans quota. Pour des appels très fréquents ou une intégration dans un produit, écrivez à sales@atmart.ltd : des clés et des quotas dédiés arriveront sur un service séparé, sans rien retirer de cette API gratuite.
