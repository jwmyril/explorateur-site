API pública del Explorador de Haití

Todos los datos del Explorador, en archivos JSON servidos como el sitio: gratuitos, sin clave y sin registro. Cada valor lleva su fuente, su año y su estado.

Lo que garantiza la v1

  • Una dirección de /api/v1/ no cambia de forma: se puede añadir un campo, ninguno desaparece ni cambia de nombre.
  • Lo que rompería un programa existente irá a /api/v2/, y la v1 seguirá disponible.
  • Los valores son los de los archivos publicados, sin cambios; un valor ausente es null, nunca cero.

Direcciones

DirecciónContenido
/api/v1/index.jsonVersión, fecha de actualización y lista de direcciones
/api/v1/territoires.jsonLos 192 territorios: país, departamentos, distritos, comunas
/api/v1/indicateurs.jsonLos 130 indicadores: nombres, unidades, definiciones y límites en 4 idiomas
/api/v1/indicateurs/IND-POP-001.jsonLos valores de un indicador, comuna por comuna
/api/v1/communes/HT0111.jsonTodos los valores de una comuna (por código, p. ej. HT0111)

Ejemplos

curl -s https://explorateur.atmart.ltd/api/v1/communes/HT0111.json

# Python
import json, urllib.request
req = urllib.request.Request("https://explorateur.atmart.ltd/api/v1/indicateurs/IND-POP-002.json",
                             headers={"User-Agent": "mon-projet/1.0"})
v = json.load(urllib.request.urlopen(req, timeout=30))
print(v["valeurs"][0])

// JavaScript
fetch("https://explorateur.atmart.ltd/api/v1/territoires.json").then(r => r.json()).then(console.log);

Uso intensivo

Identifique su programa con una cabecera User-Agent (por ejemplo «mi-proyecto/1.0»): el cortafuegos del sitio rechaza (error 403) las solicitudes que llevan el identificador por defecto de algunas bibliotecas, como urllib de Python. requests, R, curl y los navegadores funcionan sin ajuste.

Los archivos se sirven sin cuota. Para llamadas muy frecuentes o una integración en un producto, escriba a sales@atmart.ltd: claves y cuotas dedicadas llegarán en un servicio aparte, sin retirar nada de esta API gratuita.
